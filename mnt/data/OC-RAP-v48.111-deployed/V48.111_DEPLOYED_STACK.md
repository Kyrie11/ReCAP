# V48.111 submission deployed stack

This package deliberately separates **scientific audit mechanisms** from the **deadline deployment path**.

## Deployed owner

The three-regime launcher evaluates the frozen `ocrap_v48_80_dcp_drfc_bcde_rifa_pistc_main` checkpoint and its frozen per-bucket calibration. It does not insert V48.110 topology or V48.111 CNRO probe weights into planning.

The fail-closed checker requires the checkpoint to retain the V48.80 owner contract:

- observation-consistent semantic recovery source;
- active-set alignment;
- route and persistent-reentry semantics;
- actuator projection;
- nested root-tail source scaffold and tail localization;
- RIFA ordering with `Top-K=5` and absolute admission before the frozen relative filter;
- boundary transport OFF;
- class-local/path-stop/projection-fidelity/occupancy/reachability/structured-tail branches OFF;
- no regime router;
- frozen Safe/Near/Contact calibration.

## Why no finetune

V48.109--111 are audit-only causal tests, not source-GO checkpoints. Finetuning before the held-out three-regime run would change the checkpoint/calibration pair and would require a new calibration and source attribution. The submission path therefore fails closed on any attempt to combine CNRO audit and deployment.

## Scientific status

This is the strongest **evidence-frozen submission configuration**, not a claim that the absolute source has reached its historical source-freeze gate. The closed-loop outputs must be reported as submission diagnostics unless/until the preregistered source gate is satisfied.
