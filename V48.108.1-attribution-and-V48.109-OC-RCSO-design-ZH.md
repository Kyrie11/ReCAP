## 2. 核心理论推进

### 2.1 Injective reparameterization preserves information, not probe readability

raw candidate pathway 与 projected candidate pathway 经满列秩线性映射相连，因此结构上不丢失 candidate information。独立训练的有限样本/正则化 probe 却产生不同 AUC，说明：

`linear-probe STOP != information-theoretic absence`。

后续不能再通过增加 projection width/rank 解释当前缺陷。

### 2.2 Local action ranking 与 population-invariant orientation 分离

raw Support 的 dev-Near AUC 约 0.852、shuffle margin 约 +0.508、top-1 lift +0.6；同时 certificate-Near AUC 约 0.345、shuffle margin为负。并且 raw Support top-1 在 6/8 cell 有 material lift。

这表示很多 scene 内已经存在“哪个 candidate 更好”的信息，但不同 scene/population 的 score 方向/尺度没有统一。

### 2.3 Invariant orientation 应改写为 context-conditioned orientation field

当前更合理的目标不是一个场景无关常向量 `w`，而是同一个跨 population 共享的场景条件化方向场：

`omega(c) = w + W c`

`score(u,c) = u^T omega(c)`。

Near 中这个正方向表示建立/保持 support/reserve；Contact 中同一个 recovery-positive 语义表示偿还负 recovery debt。`c` 可以随场景变化，但映射 `c -> omega(c)` 必须跨 observation population 共享。

## 3. V48.109 OC-RCSO

全称：Observation-Consistent Raw Candidate-Scene Convex Relational Orientation Audit。

### 3.1 固定输入

Candidate response `u`：

- Support: raw candidate-minus-nominal delta，156D；
- Reserve/debt: `delta * (1 + tanh(raw_nominal_state))`，156D。

Scene context `c`：固定 240D：

- agent_summary 8D；
- agent raw tokens 的 permutation-invariant mean/std/max/min：40D；
- BEV 14D；
- route 70D；
- map 70D；
- dynamics 38D。

不使用 Near/Contact runtime ID，不做 post-hoc feature selection。

### 3.2 两个严格对照 family

使用完全相同的闭式凸 solver：

1. Base：`phi_base(u)=u_scaled`；
2. Relational：`phi_rel(u,c)=[u_scaled, vec(u_scaled outer c_standardized)]`，37596D。

这样可以区分：

- Base GO：V48.108 STOP 主要是 probe optimization/conditioning；
- Base STOP + Relational GO：scene relation 才是 causal missing statistic。

### 3.3 严格凸唯一解

每轴求解：

`min_w weighted_mean (x_i^T w-y_i)^2 + lambda ||w||^2`

`lambda = 1/N_axis`。

label 映射到 {-1,+1}，class-balanced；无 intercept。正 ridge 使问题 strictly convex，解唯一。实现使用 float64 sample-dual 闭式线性方程，不用 Adam、LR、epoch 或 lambda sweep；记录 normal-equation residual。

因此如果 V48.109 STOP，不能再归因于局部最优、epoch 不够或 Transformer optimization。

### 3.4 nominal zero

candidate response 仅 RMS 缩放、不中心化，所以 `u=0 -> phi=0 -> score=0`。scene context 可以标准化，因为所有 relation term 都乘以 u。这个 audit 保持 nominal-zero counterfactual semantics。

### 3.5 Gate

Support / Reserve 均沿用：

- AUC >= .65 且 true-shuffle >= +.05：>=6/8；
- >=3/4 roles 且 Near+Contact 都出现；
- top1 lift >= +.10：>=4/8，Near+Contact 都出现。

### 3.6 预注册 branch

- Base Support+Reserve GO：candidate-only convex carrier；不增加 relation/Transformer。
- Relational Support+Reserve GO：支持 context-conditioned recovery orientation field；下一步一次 nominal-invariant relational carrier integration。
- Relational Support GO / Reserve STOP：只审计 signed debt-flow relational structure。
- Relational Reserve GO / Support STOP：只审计 support-establishment constraint topology。
- Relational 两轴 STOP：关闭 bilinear relation family；进入 candidate-to-agent active-constraint/topology audit，不扩通用 encoder。

`OC-MERO + actuator-realizable executable recovery + counterfactual equivalence-partition transport + identifiability before capacity + support-establishment/signed reserve-debt + recovery base-state chart + RIFA`。
